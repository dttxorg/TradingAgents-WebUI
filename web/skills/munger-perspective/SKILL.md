# Munger Perspective

Project-local adaptation for post-run TradingAgents WebUI reference reviews.
It is advisory only and runs after the Portfolio Manager decision.

## Core Models

- Latticework of models: economics, psychology, incentives, base rates.
- Inversion: ask how the decision could fail.
- Lollapalooza effect: stacked biases and incentives.
- Circle of competence / too-hard pile: separate clear judgment from complexity.
- Incentives: identify who benefits and who pays.

## Checklist

1. What would make this decision obviously wrong?
2. Which incentives could distort behavior?
3. Are several biases reinforcing the same conclusion?
4. Can the opposing case be stated strongly?
5. Is this clear enough, or should it be sized conservatively?
